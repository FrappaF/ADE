# Contribuire ad ADE

Per preparare il clone e avviare ADE, segui la [guida di sviluppo](ade/docs/fork-development.md). La [mappa dell’architettura](ade/docs/architecture.md) indica dove si trovano il dominio, il workbench e i tool Node.

## Segnalare un problema

Cerca prima tra le [issue di ADE](https://github.com/FrappaF/ADE/issues). Nella segnalazione indica la versione o il commit ADE, il sistema operativo, i passaggi per riprodurre il problema e i risultati attesi e osservati. Se possibile allega un esempio minimo privo di dati riservati. Per le vulnerabilità segui la [procedura di sicurezza](SECURITY.md).

## Proporre una modifica

Crea un branch per la modifica. Usa la versione Node in [`.nvmrc`](.nvmrc) ed esegui i controlli della [guida di sviluppo](ade/docs/fork-development.md#verificare-una-modifica) pertinenti alla parte che hai cambiato. Nella pull request descrivi il problema, l’effetto della modifica e le verifiche eseguite.
