# States

Open this folder with **Open Project**. Press F1, choose **Ordito: Simulate State Machine**, then select `checkout.paid`. The report should end in **Paid**. Other cases include `checkout.dedup-reopen`, `checkout.failed-charge` and `checkout.final`.

Work on a copy of the entire folder, including hidden `.ordito` data. Make changes in Ordito and keep the original archive so you can start over.
