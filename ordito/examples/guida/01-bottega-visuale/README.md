# Bottega visual tour

Open this folder with **Open Project**. Start with **Struttura acquisto** and try the three other purchase views. Then open **Struttura resi**, **Flusso rimborso**, **Sequenza reso** and **Stati richiesta di reso**. Follow exercises T1–T5 in Part I of the guide.

Work on a copy of the entire folder, including hidden `.ordito` data. Make changes in Ordito and keep the original archive so you can start over.
