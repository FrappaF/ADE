# Ordito user guide projects

Start with Part I of the guide. Use **Open Project** on `01-bottega-visuale` to explore the **Acquisto** and **Resi e rimborsi** features across eight views.

In Part II, build Mercato. Use **Create Project** in the empty `07-mercato-laboratorio/inizio` folder. The `tappe` folder contains two checkpoints, and `soluzione` contains 18 views across 16 notations. The `moduli` folder holds separate Ordito project roots for quantity, interactions, states and messaging. Run `npm test` and `npm start` in the `codice` subproject or open it with **Import Codebase**. Folders 02–06 also provide the same starting points as standalone projects.

For the AI exercises, open `07-mercato-laboratorio/codice-ia` with **Import Codebase** for L17 and `07-mercato-laboratorio/moduli/generazione-ia` with **Open Project** for L18. **Acquisto** and **Resi** share the **Ordine** contract in both exercises. Start each lesson with a copy of its folder.

To try importing a standalone source project, extract a copy of `08-mercato-codebase` and select it with **Import Codebase**. Use the shared order store and local events to trace evidence across **Acquisto** and **Resi**. [Instructions and tests](08-mercato-codebase/README.md)

Copy each entire folder, including hidden model files, and edit the model in Ordito. Open the subproject for your lesson inside `07-mercato-laboratorio`. The checkpoints capture the project as it was saved at the end of L3 and L5.

The local exercises work without an AI account. The executable examples use the Node.js runtime specified in the guide. The materials contain synthetic examples and exclude personal Git history, credentials, AI sessions and import caches. Deployment, network and database schemas describe the design of the sample system.
