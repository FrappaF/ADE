# Messaging

Open this folder with **Open Project**. Press F1, choose **A.D.E: Simulate Messaging**, then select `checkout.messaging`. Follow L15 to publish `ordine-guida-1` and deliver it to `workers/A`. The simulation runs locally.

Work on a copy of the entire folder, including hidden `.ade` data. Make changes in ADE and keep the original archive so you can start over.
