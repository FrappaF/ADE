# States

Open this folder with **Open Project**. Press F1, choose **A.D.E: Simulate State Machine**, then select `checkout.paid`. The report should end in **Paid**. Other cases include `checkout.dedup-reopen`, `checkout.failed-charge` and `checkout.final`.

Work on a copy of the entire folder, including hidden `.ade` data. Make changes in ADE and keep the original archive so you can start over.
