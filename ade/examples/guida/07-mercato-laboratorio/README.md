# Mercato workshop

Follow Part II of the guide, from L1 through L21. Open the project root listed for each lesson.

| Folder | Contents |
| --- | --- |
| `inizio` | Empty workspace for **Create Project** and building the model from scratch |
| `tappe/01-confini` | Saved checkpoint after L3 with an overview, C4 Context and Use Case. Automatic views are still empty. |
| `tappe/02-architettura-dati` | Saved checkpoint after L5 with context, goals, C4, ERD and a data schema |
| `soluzione` | Three features and 18 views across 16 notations |
| `moduli/quantita` | Rule template, cases and a solution that sets the maximum to 10 |
| `moduli/interazioni` | Checkout with an alternative, a reference and an optional notification |
| `moduli/stati` | Executable flat state machine and independent cases |
| `moduli/messaggi` | Queue and topic topology and cases |
| `codice` | Dependency-free JavaScript module, seven tests and a demo |
| `codice-ia` | Codebase with **Acquisto** and **Resi**, a shared in-memory store and five tests for L17 |
| `moduli/generazione-ia` | Model with **Acquisto**, **Resi** and seven independent cases for generating the first source files in L18 |

The modules keep the names and contracts of the verified fixtures so you can compare your results with the guide. Each module is a standalone exercise in the same sample domain. The full set of 18 views describes the store design. The checkpoints capture the manual build up to each milestone. They preserve project identities through that lesson, and unused automatic views are empty.

Edit the model with ADE forms. The deployment, network and data schema document design choices. Work on a copy and keep the original package to repeat the workshop.
